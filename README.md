# Café Sales Interactive Dashboard – Swynex Technology

## Project Overview

This project focuses on creating an interactive dashboard to analyze café sales data using Microsoft Power BI. The dashboard helps understand sales performance, transaction volume, payment methods, popular items, and sales across different locations.

## Internship

* **Company:** Swynex Technology
* **Task:** Task 3 – Interactive Dashboard
* **Tool Used:** Microsoft Power BI
* **Dataset:** Cleaned Café Sales Dataset

## Objectives

* Analyze overall café sales performance.
* Display the total number of transactions.
* Compare sales across different payment methods.
* Analyze sales by item.
* Compare sales across café locations.
* Present key information through clear and interactive visualizations.

## Dashboard Visualizations

1. **Total Sales** – Displays the sum of total spending.
2. **Total Transactions** – Shows the distinct count of transaction IDs.
3. **Payment Method Analysis** – Compares sales across payment methods.
4. **Item-wise Sales Analysis** – Shows sales for different café items.
5. **Location-wise Sales Analysis** – Compares sales across locations.

## Tools and Technologies

* Microsoft Power BI Desktop
* Power Query
* Data Visualization
* Café Sales Dataset

## Key Insights

* The dashboard provides an overview of total sales and transaction volume.
* Sales can be compared across different payment methods.
* Item-wise analysis helps identify items contributing more to sales.
* Location-wise analysis helps compare sales performance across locations.
* Visualizations make it easier to identify patterns and support data-driven decisions.
